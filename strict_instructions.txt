6. VEHICLE COMPLIANCE CARD — SECURE QR VERIFICATION

Implement a professional digital Vehicle Compliance Card for registered SACCO vehicles.

Each issued compliance card must include a unique, secure QR code.

6.1 Compliance card information

The card should support the following information, where applicable:

- SACCO/company logo.
- Company name.
- Vehicle registration number.
- Vehicle reference or fleet number.
- Registered owner or authorised operator.
- Assigned route.
- Compliance status.
- Certificate/reference number.
- Issue date.
- Expiry date.
- Issuing officer.
- QR code for online verification.

Use a professional, printable layout suitable for physical presentation and digital distribution.

6.2 QR code security

Generate a unique cryptographically secure verification token for every issued compliance certificate.

The QR code must point to a public HTTPS verification endpoint, for example:

"https://nhtsms.bagovi.com/verify/compliance/<secure-token>/"

The token must:

- Be unpredictable and sufficiently strong.
- Be unique to the issued certificate.
- Not expose member personal information.
- Not contain sensitive vehicle or financial information.
- Be protected against unauthorised modification or enumeration.
- Be revocable when necessary.

Store and validate verification tokens securely. Prefer storing a cryptographic hash of the token where the implementation permits secure verification.

Do not use sequential database IDs as QR verification secrets.

6.3 Public verification page

A person scanning the QR code must be able to verify the certificate without logging into the SACCO system.

The public verification page must display only the minimum information necessary to establish authenticity.

It must check the live certificate status against the database rather than trusting information printed inside the QR code.

Support the following verification outcomes:

- VALID
- EXPIRED
- REVOKED
- SUSPENDED
- INVALID
- SUPERSEDED

The verification result must clearly communicate whether the compliance certificate is currently valid.

Do not expose:

- Member national identification numbers.
- Personal contact information.
- Private financial information.
- Internal administrative records.
- Login credentials.
- Unnecessary personal information.

Implement rate limiting, secure token validation, appropriate caching controls and protection against enumeration.

6.4 Compliance lifecycle management

Authorised staff must be able to:

- Issue compliance cards.
- View existing cards.
- Download and print cards.
- Renew certificates.
- Revoke certificates.
- Review certificate history.
- Regenerate QR codes when security requires it.
- Track expiry dates.
- Identify expired or suspended vehicles.

Record every issue, renewal, revocation and status change in the audit trail.

A revoked or superseded certificate must not continue to appear valid merely because an old printed card still exists.
